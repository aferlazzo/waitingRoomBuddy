Install Waiting Room Buddy

For your Android phone. This installs WRB with its own app icon.

Download Waiting Room Buddy
  1. Download WRB, then open the downloaded file.
  2. If Android asks, allow this browser to install this app. Keep Play Protect enabled and allow its scan.
  3. If Play Protect asks to scan WRB, allow the scan. If it shows an unfamiliar-app warning, review the details and use the option to continue installation if offered.
  4. Tap Install, then Open.

Reopen Buddy from the Waiting Room Buddy icon in your apps.

Android version 1.0. Buddy uses the existing WRB service and needs an internet connection for AI responses. Windows and iPhone cannot install this Android package.
