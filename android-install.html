Install Waiting Room Buddy

Install the Android app, then add its persistent WRB home-screen icon.

1. Download Waiting Room Buddy
  1. Open the downloaded Waiting-Room-Buddy.apk file.
  2. If Android asks, allow this browser to install the app. Keep Play Protect enabled and allow its scan.
  3. If Play Protect shows an unfamiliar-app warning, review its details and continue only if Android offers that option. If it blocks installation, follow the reason shown by Android.
  4. Tap Install (or Update), then Open.
  5. In WRB, tap Add home-screen icon and approve Android’s Add to home screen prompt.

Already installed or updating an earlier WRB? This button opens the app’s icon setup directly:

2. Set up home-screen icon

After Android confirms the icon, tap the WRB icon to open Waiting Room Buddy as a standalone app. You can return here to add the icon again if you remove it.
